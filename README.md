# Arian Nouri — Developer Portfolio

Personal portfolio showcasing web development, embedded systems, cybersecurity interests, and technical projects.

**Website:** https://arinouri.ca

## Overview

This repository contains the source for my portfolio website. The site presents my background, selected work, and interactive browser experiences.

## Technology

- HTML, CSS and JavaScript
- Three.js for browser-based 3D elements
- CryptoJS for client-side cryptography demonstrations
- Static site deployment

## Repository structure

- `index.html` — main site layout and sections
- `style.css` — styles, responsive presentation and themes
- `script.js` — interactive behavior
- `vault.html` — additional interactive page

## Run locally

Clone the repository and serve the root directory with any static web server. For example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
